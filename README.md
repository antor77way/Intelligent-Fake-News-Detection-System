# AI-Based Fitness Guidance Bot

## Project Overview
This project is a simple AI-based fitness guidance bot built using **PHP** and a **free AI API (OpenAI)**. Users can ask fitness-related questions on a website and receive intelligent answers from the bot. The goal is to demonstrate the concept of AI in fitness guidance in a basic, easy-to-understand format.  

## Features
**Chat Interface:** Users can ask fitness questions via a chatbox.
**AI-Powered Answers:** The bot uses a free AI API to provide guidance.
**Responsive Design:** Basic HTML, CSS, and JavaScript for simple interaction.
**Easy to Extend:** Future features can include backend tracking and personalized recommendations.

## Technology Stack
 **Frontend:** HTML, CSS, JavaScript
 **Backend:** PHP
 **AI Integration:** OpenAI Free API (ChatGPT model)
 **Optional:** Database (MySQL) for saving chats, user profiles, or fitness logs

## How It Works
1. User types a fitness-related question in the chatbox.
2. Frontend sends the message to the PHP backend.
3. PHP calls the AI API and gets a response.
4. The response is displayed back in the chat interface.
